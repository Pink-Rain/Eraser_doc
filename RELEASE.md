# Eraser Doc 0.1.0 — L'éditeur des documents quitte Eraser

- **L'éditeur des documents de campagne** (lettres, parchemins, pages de grimoire) vit maintenant
  dans cette extension : `/extension/doc/campagne/<id>`, ouvert depuis le menu (Dossier ›
  Document) et le Créateur de session (« Écrire un document », « Modifier »). Mêmes fonds, mêmes
  polices, même rendu ; les documents déjà écrits s'ouvrent tels quels.
- Réservé aux MJ (de la campagne) et aux administrateurs. Les joueurs lisent toujours les
  documents donnés depuis leur inventaire, dans Eraser.
- Demande Eraser 0.1.1-alpha.278 ou plus récent.
